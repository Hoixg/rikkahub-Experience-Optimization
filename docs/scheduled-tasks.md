# 定时任务与后台运行

定时任务支持新建会话、继续会话、重新生成。继续会话使用执行时的最新上下文；重新生成复制截至所选用户消息的上下文和附件，在新会话回答，保留原会话。任务可覆盖本次模型，保留助手隔离、工作区、MCP 与工具审批。

## 时间与执行

使用 AlarmManager 精确闹钟，支持单次、每日、每周、间隔；每日和每周支持本地日期范围，提供工作日快捷选择。默认每日 09:00，间隔 24 小时（最短 15 分钟），每周周一至周五。时间或时区变化后重建排程。缺少精确闹钟权限时暂停自动排程，允许停用草稿及立即执行。

立即执行不修改启用状态或定时闹钟；每个任务只能有一个活动运行。重复立即执行返回当前状态，运行期间新到的定时触发记录为跳过并推进排程。忙碌会话等待空闲，用户排队消息优先，等待任务按触发时间执行；等待不自动过期。有精确闹钟权限时每 15 分钟检查，否则启动应用或回到前台后检查。

生成累计上限 10 分钟，排队和等待审批不计时。审批恢复同一个运行；进程中断的生成记为失败，不自动重复发送。结果落库后释放占用。修改活动任务内容或删除前须先取消；停用只影响未来排程。

任务启用/停用统一在列表开关控制，编辑页保存时保留原启用状态。新任务有精确闹钟权限时默认启用，无权限时保存为停用任务，可立即执行。编辑页将两个通知开关合并为“通知提醒”，可选不通知、仅显示状态、显示内容；新任务默认显示内容，旧任务保留通知选择。

编辑任务时可切换执行助手；切换助手会清空原助手的目标会话和重新生成消息，随后只能选择新助手已有的会话。模型使用通用模型选择器，可选择已配置模型作为本次覆盖，也可清除覆盖并沿用助手或会话设置。

## 后台运行与通知

设置页和任务页共用后台运行与通知页面，通知相关入口统一为“通知权限”，授权后可进入系统通知设置调整各类通知；不再提供独立的聊天完成通知开关或通知渠道入口。运行状态只展示前台服务和 CPU 唤醒锁。保留旧权限页及通知设置路由。

仅生成期间使用前台服务和有期限的 CPU 唤醒锁，等待或结束时释放。全天保活已移除，旧设置和旧备份不再启用它。通知权限、电池豁免和厂商自启动是改善运行表现的设置，不阻止立即执行。自启动状态显示未知并提供厂商设置入口，失败回退应用详情。

通知区分完成及运行渠道，保留原渠道 ID。生成期间仅保留系统要求的普通前台服务通知，不更新消息内容、不申请实时通知提升权限。聊天在后台生成结束后按系统通知授权和渠道设置发送完成提醒；定时任务仍保留任务级通知和预览选项，默认开启，关闭通知仍记录历史。实时生成进度、全局通知隐私及独立聊天完成通知开关已移除，旧设置及旧备份中的对应选项被忽略。

## 数据及工具

数据库 33→34 迁移保留原排程并导入可恢复的旧结果、运行和审批记录。历史保留全部未结束记录及最近 20 条结束记录；删除任务不删除生成的会话。

`scheduled_task` 只管理所属助手任务，支持 `list/create/update/delete/set_enabled/run_now/history/cancel_run`。立即执行需要工具审批；执行配置包含 `mode/target_conversation_id/target_user_message_id/model_override_id/notify/show_preview`。

设备验收需覆盖 API 26/31/33/34/36/37 的锁屏、后台触发、权限撤销、通知渠道、省电策略、取消、超时和并发资源释放。厂商自启动入口须在对应设备确认。
